# RipoBot Brand Assets (source files)

Generated 2026-10-14 as part of the RipoBot (OpenMausBot fork) rebrand sprint.
Style reference: `~/workspace/your_files/Ripo-Team-logo.png` (Ripo Team brand).

Visual direction: a friendly cyan-blue robot head whose face is a chat bubble
(happy eyes, small smile), surrounded by the Ripo Team multicolored-star motif
(purple, green, red, pink, orange, yellow). Wordmark "RipoBot" in bold rounded
type: "Ripo" cyan-blue (#00A0DC-ish), "Bot" red-pink — echoing the RIPO/TEAM
color split. Flat-vector, playful, techy. Original design — no trademarked
characters copied.

| File | Size | Intended use |
|---|---|---|
| `ripobot-logo.png` | 1600x1600 | Primary logo (mark + wordmark) on light backgrounds — website header, installer wizard, about screens, README. |
| `ripobot-icon-1024.png` | 1024x1024 | Square app icon, bold mark only (no text), reads at small sizes — Windows installer/taskbar icon source, sitey.my favicon base, HF Space avatar. |
| `ripobot-mascot.png` | 1600x1600 | Cute robot mascot character (SupaMaus replacement) — website hero, welcome screens, docs, error/empty states. |
| `ripobot-logo-dark.png` | 1600x1600 | Dark-background variant (glowing white outline, dark navy bg) — website dark mode, installer dark theme, splash screens. |

Notes:
- All PNG, RGBA. Downscale from these masters when producing ICO/ICNS/WebP
  deliverables; never upscale.
- These are working sources, not user-facing documents. Canonical brand
  source stays `~/workspace/your_files/Ripo-Team-logo.png`.
